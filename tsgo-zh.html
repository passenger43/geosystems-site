TS Go!

面向测量人员的现场工具：全站仪、项目、DXF、放样和控制。

  • 通过 Bluetooth 连接手机与全站仪。
  • 处理项目和 DXF 放样文件。
  • 检查测点相对于设计线、点、对象或曲面的位置。

功能

TS Go! 的功能

应用围绕简单的现场流程设计：打开项目、选择对象、测量点位，并立即理解测量结果。

全站仪

连接支持的仪器并接收测点坐标。

DXF 项目

打开放样文件，显示 CAD 对象，并处理直线、点、圆弧和圆。

放样

相对项目的现场参数：里程、偏距、高/低、左/右、前/后和转角。

基准线

通过点创建工作基准线，并快速反转线方向。

测量

用于测点保存、导出和清理的轻量工作空间。

曲面

相对设计 3D 曲面的高程控制正在当前版本中继续开发。

兼容性

全站仪通信协议

TS Go! 包含常见全站仪系列的通信配置，可直接从仪器接收测量坐标。

Sokkia / Topcon SET

适用于使用 SET 协议的仪器通信配置。

Leica

Leica GSI 和 GeoCOM 通信配置。

Nikon / Spectra Precision

适用于兼容 Nikon、Spectra Precision 和 Trimble 型号的 Nikon 配置。

Topcon GTS 与兼容仪器

Topcon GTS 配置，以及部分 South、Kolida、CHC、Sanding 和 Gowin 型号使用的兼容协议。

兼容性取决于仪器型号、固件、所选协议以及 Bluetooth/COM 参数。外业前请使用具体仪器测试通信。
